# E-Commerce Sales Analytics and Visualization System

## Project Overview
The E-Commerce Sales Analytics and Visualization System is a Python-based desktop application designed to analyze e-commerce sales data and display useful insights through graphical visualizations.

The project uses Python libraries such as NumPy, Pandas, and Matplotlib to process sales data, calculate revenue, and generate charts.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Tkinter
- CSV

## Features
- Load and analyze sales data from a CSV file.
- Calculate total revenue.
- Display sales summaries.
- Analyze product and category-wise sales.
- Generate graphical charts and visualizations.
- User-friendly graphical interface using Tkinter.
- Validate sales data.

## Project Files
- `main.py` – Main Python application.
- `sales_data.csv` – E-commerce sales dataset.
- `requirements.txt` – Required Python libraries.

## Installation and Setup

**Step 1:** Clone the repository.

```bash
git clone https://github.com/Deepu-webs/ECommerce-Sales-Analytics.git
```

**Step 2:** Open the project folder.

```bash
cd ECommerce-Sales-Analytics
```

**Step 3:** Install the required libraries.

```bash
pip install -r requirements.txt
```

**Step 4:** Run the application.

```bash
python main.py
```
