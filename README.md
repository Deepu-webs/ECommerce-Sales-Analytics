# E-Commerce Sales Analytics and Visualization System

## Project Overview
The E-Commerce Sales Analytics and Visualization System is a Python-based desktop application developed to manage, analyze, and visualize e-commerce sales data.

It helps users calculate total revenue, track sales records, analyze product performance, and view sales trends through graphical charts.

The application uses a Tkinter graphical user interface (GUI) and Pandas for data processing.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Tkinter
- CSV
- OS Module
- OpenPyXL

## Features
- Add new sales records.
- Update existing sales records.
- Delete sales records.
- Search sales by product name.
- Filter sales records by date.
- Calculate total revenue and total sales.
- Display total units sold.
- Identify the best-selling product.
- Generate product-wise revenue charts.
- Generate category-wise revenue charts.
- Display monthly revenue trends.
- Export sales reports in CSV format.
- Export sales reports in Excel format.
- Validate sales data.

## Project Files
- `main.py` – Main Python application.
- `sales_data.csv` – E-commerce sales dataset.
- `requirements.txt` – Required Python libraries.
- `README.md` – Project documentation.

## Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/Deepu-webs/ECommerce-Sales-Analytics.git
```

### Step 2: Open the Project Folder

```bash
cd ECommerce-Sales-Analytics
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
python main.py
```

## Python Libraries
- **Pandas:** Used for loading, processing, filtering, and analyzing sales data.
- **Matplotlib:** Used to create sales charts and graphical visualizations.
- **Tkinter:** Used to develop the graphical user interface.
- **OpenPyXL:** Used for exporting sales reports to Excel files.
- **OS:** Used for checking file existence.
